How these case studies are written

i.

Software builds are anonymized.

Titles describe the system, not the business. The law-firm, WordPress and mobile-app case studies are the exception: they cover public sites and apps, so each links to its live site or store listing.

ii.

Described from the evidence.

Software builds are described from the repository. Law-firm sites are described from their public pages, page source and server responses.

iii.

No invented metrics.

Business value is what the system enables. We do not quote numbers the code cannot prove.
